# Royalweave

Royalweave is an e-commerce web application designed for browsing and purchasing fabrics and shemaghs. The system provides customer account management, shopping cart functionality, purchase history, and an administrative interface for managing products.

## Features

- User registration and login
- User profile management
- Browse fabrics and shemaghs
- Product details
- Add products to shopping cart
- Manage and remove cart items
- Complete purchases
- View purchase history
- Admin dashboard
- Add, edit, delete, and manage product availability
- MySQL database integration

## Technologies Used

- PHP
- MySQL
- JavaScript
- HTML
- CSS

## How It Works

1. Users can create an account or log in to the system.
2. Products can be browsed and viewed through their product pages.
3. Users can add products to their shopping cart and manage selected items.
4. Purchases can be completed and viewed later through the purchase history.
5. Administrators can manage products and their availability through the admin interface.
6. Application data is stored and managed using a MySQL database.

## Purpose

The project demonstrates the development of a database-driven e-commerce website using PHP, MySQL, JavaScript, HTML, and CSS.
